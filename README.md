# 日本株・株式レーダー

5種類の検索結果を1画面に統合し、複数部門で重なる銘柄を上位表示するStreamlitアプリです。

## 検索部門

1. 資金流入
2. 業績上方修正・業績加速
3. 新高値・ブレイクアウト
4. 連続増益・最高益
5. 高配当・優良株

## チャート

各ランキング表の銘柄行をクリックすると、ローソク足、出来高、25日・75日移動平均線を表示します。表示期間は3か月、6か月、1年、2年から選択できます。

総合ランキングは、5部門のうち得点上位3部門を重視し、70点以上の部門数を重複評価に加えます。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

見本データですぐ画面を確認できます。「オンライン取得」を選ぶとYahoo Finance経由で対象銘柄を更新します。

## 上方修正データについて

会社予想の上方修正率は、オンライン取得だけでは安定して取得できません。適時開示などを確認し、CSVの `forecast_revision` 列へ修正率（%）を入力するとスコアへ反映されます。
